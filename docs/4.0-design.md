# SuperClipboard 4.0

## 旧版审查

- 3.6 的主窗口同时负责模式切换、搜索、条目选择、备忘录、回收站、快捷粘贴和对话框。备忘录和回收站还需要先在设置中启用。改为稳定的工作区导航，一次选中、在详情面板查看原文或操作，全局快捷入口仍可一键粘贴。
- 原生层已有单实例、托盘、目标窗口恢复、图文分类、PostgreSQL 连接池和编辑冲突检测。保留这些经过使用的基础能力，拆开桌面生命周期、传输和提醒，使用同一套前端查询和错误反馈。
- v1.0.0 使用 `com.superclipboard3.app/clipboard.db`，仅有剪贴板；v2 增加备忘录、排序和归档，存在旧式 JSON 备份；后续版本引入 PostgreSQL 的 `superclipboard` schema 和包含校验的 `.scbackup`。旧图片以 Base64 保存，备忘录图片内嵌于正文，没有独立附件表。
- 3.x 原地恢复先清空数据。4.0 保留原始数据库文件，使用新的 `workspace.db` 和 PostgreSQL `superclipboard_v4`，首次升级通过预览导入。旧库读取和新库写入分别使用快照与事务。

## 界面入口

默认保留 3.x 的紧凑布局与原有控件。宽屏工作台通过「实验功能 → 工作台模式(beta)」启用，同一开关可在工作台设置中关闭。两种布局使用同一套 4.0 存储、导入和提醒服务。经典界面的存储面板保留本地与外部切换、手动连接和已保存连接。

## 实施与验收

1. 统一工作区的历史、收藏、备忘录与回收站，接入按需读取详情、筛选、原格式编辑、复制粘贴及错误反馈。
2. 接通旧库发现、文件和 PostgreSQL 格式转换、预览、去重合并及可移植备份。验证早期 schema、坏包、相同数据多次导入和既有数据保留。
3. 持久化每台设备上的提醒，使用 Windows 计划任务覆盖进程退出与重新登录，后台原生调度覆盖托盘和唤醒。验证一次性、重复、修改、取消和过期补发。
4. 走通本地和外部存储的连接切换以及 Windows 构建与验收，更新使用说明与发布版本。
