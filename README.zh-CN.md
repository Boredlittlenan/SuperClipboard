# SuperClipboard 4.0

[English](README.md) · [4.0 设计与旧版审查](docs/4.0-design.md) · [版本日志](CHANGELOG.md) · [GitHub Releases](https://github.com/Boredlittlenan/SuperClipboard/releases)

SuperClipboard 是 Windows 剪贴板工作台。主窗口包含剪贴板历史、备忘录、收藏、提醒和回收站，支持中文、英文、浅色与深色主题。

## 界面模式

4.0 默认使用经典紧凑界面。打开「设置」并启用「实验功能」，然后点击标题栏的烧瓶图标，开启「工作台模式(beta)」。工作台内可在「设置 → 实验功能」关闭同一开关。选择会在下次启动时恢复，两种布局共用同一套数据。

经典界面的标题栏存储按钮提供 4.0 导入和备份。备忘录的铃铛按钮用于设置提醒。以下操作说明中的详情面板、独立提醒页和暂停捕获按钮对应工作台模式。

## 日常使用

- 复制文本、链接、代码或图片后，在「剪贴板历史」查看。可以拖入文本、链接及 PNG、JPEG、GIF、WebP 图片。「暂停捕获」暂停监听，已有记录仍可查看、编辑或复制。
- 通过分类或 `Ctrl+F` 搜索。点击打开详情，双击复制；编辑后的剪贴板条目保留原文。用星标加入收藏，或从详情转为备忘录。历史列表支持多选，选中同类条目可以合并。
- `Alt+X` 从其他应用打开快速粘贴。输入搜索后按 Enter，或选中条目后点击「粘贴」。焦点恢复失败时，内容仍已复制到系统剪贴板。可在设置中修改全局快捷键。
- 备忘录支持文字、图片和标签。剪贴板与备忘录删除后进入回收站，可按类型恢复或确认后永久删除。
- 关闭主窗口会隐藏到托盘。托盘菜单可以打开设置或退出。剪贴板登录自启由设置控制。

## 提醒

在备忘录详情中设置时间，选择一次、每天或每周。提醒页可以查看下一次时间、完成或取消提醒。一次性提醒在系统通知交付后保留为待完成。重复提醒错过多次时合并补发一次，然后恢复正常间隔。

Windows 任务计划程序在首次设置时为当前用户注册任务。主程序驻留时每几秒检查，退出后任务约每分钟检查，并在登录时检查。Windows 未运行或用户未登录时，提醒会在下次可用时补发。系统免打扰或关闭通知可能隐藏横幅，可在「设置 → 系统通知」发送测试通知。提醒存放在本机设备的独立数据库，同一 PostgreSQL 工作区的各设备分别设置。工作区导出包含历史和备忘录，提醒保留在本机。

## 从旧版导入与备份

1. 打开经典界面的「存储设置」或工作台的「存储与导入」，选择自动发现的旧版数据库，或手动选择旧 SQLite、旧 JSON 备份或 `.scbackup` 文件。使用旧 PostgreSQL 的用户，先连接同一服务器，再点「预览旧版 PostgreSQL」。
2. 检查来源、数量和样例后，点击「合并到当前工作区」。原数据库保持可用，已有工作区条目保持原状。备份校验失败会在预览阶段显示原因。写入失败时整批回滚。
3. 导入会保留可识别的分类、标签、归档、收藏、排序、原文与内嵌图片。重复内容会跳过，既有记录保留自己的收藏和归档状态。旧版的文件路径按原文本保留。
4. 「保存备份」会导出带校验的 `.scbackup`，本地和外部模式均可使用。恢复和工作区之间迁移都使用同一套导入合并流程。选择新的文件名保存备份。

## 存储与隐私

- 默认使用新的 `workspace.db`，与旧版 `clipboard.db` 并存。外部工作区使用 `superclipboard_v4` schema。
- 连接 PostgreSQL 时先验证并初始化目标 schema，成功后才切换。不同存储位置各自保存数据，使用导出和导入转移内容。
- PostgreSQL 连接地址由当前 Windows 账户的 DPAPI 保护，导出包里只包含工作区数据。工作区备份包含可读的剪贴板和备忘录内容，请保存在可信位置。使用外部数据库时可在连接地址中配置 TLS。
- 默认仅本机记录剪贴板。检查更新时会访问 GitHub Releases。

## 开发

需要 Windows、WebView2、MSVC C++ 构建工具、Node.js 22+、pnpm 10 和稳定版 Rust。

```powershell
pnpm install --frozen-lockfile
pnpm tauri:dev
pnpm lint
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml --locked
pnpm tauri:build
```

前端在 `src/workspace`。Rust 中 `commands` 接收桌面调用，存储层负责查询和写入，`transfer` 负责导入和备份，`reminders` 负责 Windows 调度与通知。详见 [4.0 设计与旧版审查](docs/4.0-design.md)。
